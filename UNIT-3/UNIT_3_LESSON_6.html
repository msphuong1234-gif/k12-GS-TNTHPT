2. Connectors: nguyên nhân → hệ quả → đối lập
  • as a result / therefore = do đó, vì vậy (hệ quả, kết luận).
  • because + S + V = bởi vì (lý do); because of / despite + N.
  • so that + S + V = để (mục đích).
  • however = tuy nhiên (đối lập); while + S + V = trong khi đó.
3. Verb patterns
  • suggest + V-ing; before / after + V-ing.
  • encourage sb to do sth; contribute to + V-ing.
  • be + adj + to V (be realistic to implement).
4. Reference words (thay thế)
  • This / These thường thay cho cả sự việc/mệnh đề trước đó.
  • which sau dấu phẩy = cả mệnh đề trước; that = vật làm chủ ngữ.
5. Cấu trúc problem-solving report & sentence function
  • Introduction: giới thiệu tổng quan (vấn đề + giải pháp sẽ bàn).
  • Problem / effect: nêu vấn đề và hệ quả (tín hiệu: as a result).
  • Solution: đề xuất hành động cụ thể (tín hiệu: we recommend).
  • Conclusion / recommendation: chốt lại (tín hiệu: therefore).
  • Thứ tự đoạn: problem → solution → result → recommendation (chú ý another, together).
