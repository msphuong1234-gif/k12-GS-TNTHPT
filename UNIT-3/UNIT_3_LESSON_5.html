2. Ngữ pháp trọng tâm

Mục đích: to + V (turn regularly to improve airflow; covered to reduce smells).
allow + O + to V: allow oxygen to circulate.
contribute to + V-ing/N: contribute to reducing waste / to wider awareness.
Mệnh đề quan hệ: that (chủ ngữ, xác định) — the organisms that break…; which (sau dấu phẩy, thay cả mệnh đề) — …, which improves…
Liên từ: however (đối lập), as a result (kết quả), in addition (bổ sung), if/unless (điều kiện).
Word families: decompose → decomposition; circulate → circulation; moist (adj) → moisture (n); qualify → quality.

3. Chiến thuật làm bài

Ordering: bám dấu hiệu First / Next / During / Finally và từ nối (For this reason, This + N).
Reading: tìm câu chứa từ khoá trong bài rồi đối chiếu từng option; NOT supported = ý trái luận điểm chính.
Paraphrase: giữ đủ ý gốc, đổi từ đồng nghĩa; cảnh giác từ tuyệt đối hoá (every, always, completely).
